# Клуб локального маркетинга — Landing Page

Одностраничный сайт для маркетингового агентства «Клуб локального маркетинга». Сайт построен на React с использованием Tailwind CSS.

## 🚀 О проекте

Сайт предназначен для привлечения владельцев офлайн-бизнеса (рестораны, салоны красоты, фитнес-клубы, магазины). Основной посыл — использование локальных инфлюенсеров для создания доверия и привлечения клиентов, вместо прямой и агрессивной рекламы.

## 🛠 Технический стек

- **React 19**: Библиотека пользовательского интерфейса.
- **Tailwind CSS**: Утилитарный CSS фреймворк для стилизации.
- **Lucide React**: Иконки.
- **Recharts**: Графики в блоке "Контекст".

## 📁 Структура проекта

- **`App.tsx`**: Главный компонент, собирающий все секции лендинга.
- **`components/`**: Папка с UI-компонентами и секциями.
  - `Hero`, `Context`, `Cases`, `Tariffs`, `CTA` и др. — отдельные блоки сайта.
  - `ui/`: Базовые компоненты (`Button`, `Section`, `FadeIn`).
- **`constants.ts`**: **Файл конфигурации контента.** Все тексты, ссылки на изображения, цены и данные отзывов находятся здесь.

## 📝 Как редактировать контент

Вам не нужно лезть в верстку (`.tsx` файлы), чтобы поменять текст или цены.

1. Откройте файл `constants.ts`.
2. Найдите нужную секцию (например, `hero` для главного экрана или `tariffs` для цен).
3. Измените текст внутри кавычек.

Пример смены телефона:
```typescript
legal: {
  ...
  phone: "+7 980 591 12 19", // Поменяйте этот номер
  ...
}
```
